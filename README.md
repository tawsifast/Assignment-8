# 🛍️ SummerShop – Modern eCommerce Platform

A modern, responsive eCommerce web application built with Next.js where users can browse and purchase summer-related products like sunglasses, outfits, skincare items, and accessories.

---

## 🌐 Live Demo
👉 https://assignment-8-mu-rust.vercel.app

---

## 🎯 Purpose

SummerShop is designed to provide a smooth, user-friendly, and real-world shopping experience. It allows users to explore products, view details, filter by categories, and manage their cart with authentication support.

---

## ✨ Features

- 🔐 Authentication system (Email & Google login) using Better Auth  
- 🛒 Add to cart functionality using React Context API  
- ➕➖ Quantity increase/decrease system  
- 📦 Dynamic product details page (Next.js routing)  
- 🎯 Category-based product filtering  
- 📱 Fully responsive design (mobile, tablet, desktop)  
- 🎨 Modern UI with Tailwind CSS and Hero UI  
- 🎞️ Animations using Animate.css  
- ⚡ Fast and optimized performance with Next.js App Router  
- 🔔 Toast notifications for user actions  
- ⏳ Loading spinner for better UX
